Access Control Policies

Declare fine-grained security policies using Tailscale JSON syntax configurations to govern mesh routing paths.

// Define aclRules to connect specific tags and users securely
{
  "acls": [
    {
      "action": "accept",
      "src": ["*"],
      "dst": ["*:80", "*:443"]
    },
    {
      "action": "accept",
      "src": ["tag:admin"],
      "dst": ["*:22"]
    }
  ],
  "ssh": [
    {
      "action": "check-routes",
      "users": ["*"]
    }
  ]
}
